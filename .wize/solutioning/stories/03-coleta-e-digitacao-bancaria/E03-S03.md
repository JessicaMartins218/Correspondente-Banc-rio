# Story: Tratamento de Pendências de Digitação e Mensagens de Erro Amigáveis

## Context
Nem sempre a proposta é aceita imediatamente pelo banco: podem ocorrer bloqueios como benefício não averbável, margem insuficiente no momento da digitação, restrição de convênio ou CPF com divergência cadastral. O robô deve capturar essas mensagens de erro do portal do banco, traduzi-las para uma linguagem clara e orientar o cliente no WhatsApp, acionando também a equipe humana quando necessário.

## Sources of truth (Shuri reads before coding)
- `.wize/planning/prd.md` (AC-03-4).
- Dicionário de mensagens de erro comuns dos portais bancários (DSV e Prata).

## Acceptance criteria
- **AC-03-4:** Dado que o portal bancário acusa uma pendência impeditiva durante a digitação (ex: margem zerada, benefício bloqueado para empréstimo no INSS ou divergência cadastral na Receita), quando o robô captura o erro da tela, então traduz a mensagem técnica para uma explicação clara ao cliente no WhatsApp e abre chamado interno para a JM Consultoria.

## Restrictions
- **Out of scope:** Desbloquear benefícios diretamente nos órgãos oficiais (o cliente precisa fazer via aplicativo Meu INSS / FGTS).
- **Protected behaviors:** Não expor stack traces ou erros de script em tela ao cliente.

## Notes for Shuri (Dev)
- Criar mapa de tradução de erros bancários `BankErrorTranslator` (ex: "Margem insuficiente" -> "Identificamos que a margem disponível para este valor está comprometida no momento. Deseja simular um valor menor?").
- Salvar o print da tela do erro para auditoria interna da consultoria.

## Validation contract
- **AC → test:** AC-03-4 → Teste de captura de modais de erro e envio da mensagem amigável no WhatsApp.

## Notes for Hawkeye (TEA)
- Bateria de testes com 5 mensagens de erro típicas de bancos para conferir a tradução em linguagem humana.

## Done means
Erros dos portais bancários tratados com elegância, informando o cliente e gerando chamado interno para a equipe.
