# Story: Coleta Conversacional de Dados Pessoais e Validação de Conta Bancária de Mesma Titularidade

## Context
Para que o robô possa preencher a proposta no portal do banco, ele precisa coletar os dados complementares do cliente (documento, data de nascimento, endereço, nome da mãe e dados bancários para o depósito). Conforme as normas do BACEN, o pagamento do crédito consignado ou FGTS só pode ser efetuado em conta de titularidade do mesmo CPF do proponente.

## Sources of truth (Shuri reads before coding)
- `.wize/planning/prd.md` (AC-03-1, AC-03-2).
- Resoluções do Banco Central sobre regras de desembolso em contas de mesma titularidade.
- Lista de instituições bancárias e validadores de agência/conta do Brasil.

## Acceptance criteria
- **AC-03-1:** Dado que a proposta foi confirmada pelo cliente, quando o robô inicia a coleta cadastral no WhatsApp, então solicita os dados complementares exigidos pelo banco (RG/Órgão emissor, data de nascimento, endereço, nome da mãe e dados da conta bancária para crédito).
- **AC-03-2:** Dado que o cliente informa os dados bancários para recebimento (banco, agência, conta ou chave PIX), quando o sistema valida os dados cadastrais, então rejeita chaves ou contas em nome de terceiros e orienta que a conta deve ser obrigatoriamente vinculada ao mesmo CPF do titular do empréstimo.

## Restrictions
- **Out of scope:** Integração de birô de crédito pago desnecessário se a validação puder ser feita por chave PIX CPF.
- **Protected behaviors:** Caso o cliente insira uma chave PIX telefone/e-mail, o robô deve solicitar preferencialmente chave PIX CPF ou dados bancários tradicionais (banco, agência, conta corrente/poupança).
