# Story: Envio do Link no WhatsApp com Orientações para Biometria Facial e Assinatura de CCB

## Context
Com o link oficial de formalização extraído do portal do banco, o robô despacha uma mensagem acolhedora e explicativa no WhatsApp do cliente, fornecendo instruções claras sobre como fazer a biometria facial e assinar o contrato pelo smartphone, garantindo alta taxa de conclusão.

## Sources of truth (Shuri reads before coding)
- `.wize/planning/prd.md` (AC-04-2, AC-04-3).
- Boas práticas de UX conversacional para onboarding biométrico.

## Acceptance criteria
- **AC-04-2:** Dado que o link de formalização foi capturado, quando o sistema formata a mensagem no WhatsApp, então envia o link ao cliente acompanhado de orientações didáticas passo a passo (preparar documento original, estar em ambiente iluminado para a biometria facial e ler o resumo do contrato).
- **AC-04-3:** Dado que o link de formalização foi enviado, quando o cliente clica no link e realiza a formalização no ambiente seguro do banco, então o status da proposta na base local é atualizado para `awaiting_bank_signature_validation`.

## Restrictions
- **Out of scope:** Coleta de selfie no chat do WhatsApp (a selfie/biometria é tirada no link oficial do banco).
- **Protected behaviors:** O link deve ser enviado com botão de clique rápido ("Assinar Contrato Agora") ou link direto com pré-visualização.
