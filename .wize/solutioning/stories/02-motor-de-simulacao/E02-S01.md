# Story: Integração com APIs de Simulação dos Bancos e Cálculo de CET e Parcelas

## Context
Ao selecionar a linha de crédito, o sistema consulta em tempo real os motores e tabelas de crédito dos bancos integrados para calcular as opções disponíveis para o cliente (valor da parcela, valor líquido liberado, taxa de juros e CET).

## Sources of truth (Shuri reads before coding)
- `.wize/planning/prd.md` (AC-02-1).
- Contratos de API das promotoras e bancos parceiros (Pan, BMG, C6, Facta, etc.).
- Normas do Banco Central sobre transparência do Custo Efetivo Total (CET).

## Acceptance criteria
- **AC-02-1:** Dado que o cliente selecionou o produto desejado (ex: Consignado INSS ou FGTS), quando o sistema envia requisição para as APIs dos bancos parceiros homologados, então compila as simulações retornadas em até 3 segundos contendo valor liberado, quantidade de parcelas, valor da parcela, taxa de juros nominal e CET.

## Restrictions
- **Out of scope:** Digitação e reserva definitiva de margem (feita apenas após escolha).
- **Protected behaviors:** Caso uma API bancária falhe ou demore mais de 2,5s, o compilador retorna as cotações dos bancos que responderam a tempo sem quebrar a simulação geral (degradação graciosa).
- **Security:** Nenhuma taxa pode ser omitida; o cálculo de CET deve ser rigorosamente auditável.

## Notes for Shuri (Dev)
- Implementar padrão *Aggregator / Scatter-Gather* assíncrono com `Promise.allSettled` e timeout de 2.500ms por provedor.
- Normalizar o formato de saída de todas as instituições financeiras parceiras em um schema unificado `SimulationOffer`.

## Validation contract
- **AC → test:** Teste com simulação paralela de 3 bancos parceiros, verificando retorno unificado em tempo ≤ 3s mesmo quando 1 banco retorna erro 500.

## Notes for Hawkeye (TEA)
- Mocks para simulação bancária com cenários de alta latência e cenários de erro de rede.
- Validar se o CET calculado confere com a fórmula do BACEN.

## Done means
Simulações multibancos integradas, com agregação concorrente tolerante a falhas e retorno com dados financeiros completos.
