# Story: Recepção de Mídia e Extração Automatizada de Dados via OCR

## Context
O cliente fotografa e envia seu documento de identidade (RG frente e verso ou CNH aberta) pelo WhatsApp. O sistema baixa a imagem de forma segura através da API da Meta e executa serviço de OCR para extração dos dados biográficos do proponente.

## Sources of truth (Shuri reads before coding)
- `.wize/planning/prd.md` (AC-03-3).
- Provedor de OCR e Documentoscopia (ex: Google Cloud Vision / AWS Textract / engine especializada em documentos brasileiros).

## Acceptance criteria
- **AC-03-3:** Dado que o bot solicita a foto do documento de identificação (RG ou CNH), quando o cliente envia a imagem pelo WhatsApp, então o serviço de OCR extrai os campos Nome, CPF, Data de Nascimento e Órgão Emissor em até 4 segundos.

## Restrictions
- **Out of scope:** Validação de autenticidade criminal ou grafotécnica manual (feita pela checagem antifraude automática).
- **Security:** Armazenamento seguro e efêmero das fotos dos documentos, protegidas com URLs assinadas temporárias de expiração curta (≤ 15 min).

## Notes for Shuri (Dev)
- Criar serviço de ingestão de mídia do WhatsApp (`GET /v1/media/{media-id}`).
- Implementar pipeline de processamento de imagem (conversão, rotação automática de orientação e envio para o OCR).
- Mapeamento regex e tipagem dos dados extraídos: `FullName`, `Cpf`, `BirthDate`, `IssuingAuthority`.

## Validation contract
- **AC → test:** Teste de extração com fixtures de imagens de CNH e RG padrão com retorno de campos corretos em ≤ 4s.

## Notes for Hawkeye (TEA)
- Mocks para a API de mídia do WhatsApp e provedor de OCR. Testar variações de formato (JPEG, PNG, HEIC).

## Done means
Imagens recebidas pelo WhatsApp são processadas e os dados textuais do documento são extraídos com precisão e associados à proposta.
