# Story: Geração e Envio de Link Seguro e Efêmero de Formalização no WhatsApp

## Context
Quando a proposta atinge o status `ready_for_formalization`, o sistema aciona a esteira do banco parceiro para gerar a minuta da CCB e emite um link web seguro, exclusivo e temporário (24h) diretamente no WhatsApp do cliente para a assinatura.

## Sources of truth (Shuri reads before coding)
- `.wize/planning/prd.md` (AC-04-1).
- API da esteira bancária parceira (emissão de minuta de CCB e token de formalização).

## Acceptance criteria
- **AC-04-1:** Dado que a proposta está aprovada para formalização, quando o sistema aciona a esteira do banco parceiro, então gera o link único e criptografado da Cédula de Crédito Bancário (CCB) e o envia no WhatsApp do cliente com prazo de validade de 24 horas.

## Restrictions
- **Out of scope:** A execução da biometria em si (coberta na story E04-S03).
- **Security:** Token assinado via JWT ou hash seguro com expiração estrita de 24 horas; link utilizável apenas uma vez para conclusão do contrato.

## Notes for Shuri (Dev)
- Criar serviço `FormalizationService` que integra com o banco parceiro, registra `formalization_token` e envia a mensagem interativa no WhatsApp com botão "Assinar Contrato Agora".

## Validation contract
- **AC → test:** Teste gerando link seguro com validação de expiração e conferência da mensagem enviada via WhatsApp API.

## Notes for Hawkeye (TEA)
- Validar comportamento ao acessar link com token expirado (> 24h) ou inválido.

## Done means
O link de formalização é gerado e enviado de forma instantânea e segura pelo WhatsApp assim que a proposta é validada.
